How the term's workflow goes
  1. After an event, open the response sheet and search for “@wpi.edu”. Fix anyone who used a personal email, since points are tracked by WPI email. This page also flags any non-WPI address it sees.
  2. Filter the sheet to the event that just happened and download it as CSV (name it raw_eventName). You can also upload the unfiltered sheet and pick the event here.
  3. First event of the term: use First event of the term, drop the raw file, download the result as fixed_eventName.
  4. Every event after: use Add an event. Drop the most recent fixed file in slot 1 and the new raw file in slot 2. Returning members get +1, new people start at 1. Download the result as fixed_eventName.
  5. Someone who submits the form twice for one event is counted once.
Files are processed entirely in your browser. Nothing you upload leaves your computer.
